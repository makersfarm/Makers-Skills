## Overview

UI/UX Pro Max is a design-intelligence skill for making web and mobile interfaces more usable, accessible, responsive, and visually coherent. It helps an implementation agent choose layout, typography, color, motion, component patterns, and review criteria with a bias toward concrete interface quality rather than abstract design advice.

Use it when you want UI work to ship with clearer hierarchy, better interaction states, stronger accessibility checks, and fewer avoidable product-design mistakes.

## When to use

- Designing or refactoring pages such as dashboards, admin panels, SaaS screens, landing pages, e-commerce flows, portfolios, blogs, or mobile apps.
- Creating or improving UI components such as buttons, modals, navbars, sidebars, cards, tables, forms, and charts.
- Choosing color systems, typography, spacing, layout, motion, responsive behavior, or interaction patterns.
- Reviewing UI code for accessibility, visual consistency, usability, or production polish.
- Aligning a feature with a product type, style direction, platform convention, or design-system pattern.

## When not to use

- Pure backend, API, database, infrastructure, or DevOps work.
- Non-visual scripts and automation.
- Performance work that does not affect interface loading, interaction, layout shift, or perceived responsiveness.
- Tasks where the user has already supplied a complete design specification and only needs a mechanical code translation.
