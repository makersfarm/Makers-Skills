# Makers Skills

Makersfarm Codex custom skills.

## Skills

- `multi-agent-maintainability-review`: Run scoped maintainability reviews with multiple subagents and consolidate recommendations.
- `ui-ux-pro-max`: Provide UI/UX design guidance for web and mobile products, including palettes, typography, layout, accessibility, and component patterns.

## Install

Install a skill by pointing Codex to the skill path in this repository:

```bash
python scripts/install-skill-from-github.py --repo Makersfarm/Makers-Skills --path skills/multi-agent-maintainability-review
python scripts/install-skill-from-github.py --repo Makersfarm/Makers-Skills --path skills/ui-ux-pro-max
```
