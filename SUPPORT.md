# Support

Use GitHub-native support paths for this repository:

- Source: browse the skill directories in [`skills/`](skills/) and open the relevant `SKILL.md`.
- Bugs: open a [bug report](https://github.com/makersfarm/Makers-Skills/issues/new?template=bug_report.yml).
- Feature requests: open a [feature request](https://github.com/makersfarm/Makers-Skills/issues/new?template=feature_request.yml).
- Pull requests: submit a focused PR when you can propose a direct fix.

Before opening an issue, check whether the skill source already documents the behavior. Include the skill name, install target, environment, expected behavior, actual behavior, reproduction steps, and relevant logs.

Do not paste secrets into public issues. Remove API keys, tokens, private URLs, personal data, and proprietary content from logs or screenshots before posting.
